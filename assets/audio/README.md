## لإضافة أو استبدال أي صوت

استبدل الملف بنفس الاسم بالظبط في **مكانين**:
1. `assets/audio/<name>.mp3`         (لزر "تجربة الصوت" ومكتبة القراءات داخل التطبيق)
2. `android/app/src/main/res/raw/<name>.mp3`  (لصوت شاشة الأذان الكاملة وإشعار الصلاة)

بعد الاستبدال، شغّل `flutter clean` قبل البناء عشان الأندرويد يلقط ملفات
raw الجديدة صح.
