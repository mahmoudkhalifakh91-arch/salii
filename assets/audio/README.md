# ملفات الأذان الصوتية

ضع هنا 4 ملفات mp3 بنفس الأسماء دي بالظبط (مطابقة لقائمة المؤذنين في شاشة الإعدادات):

- abdul_basit.mp3
- makkah.mp3
- madinah.mp3
- al_aqsa.mp3

بعد إضافتهم، زرار "تجربة الصوت" في شاشة الإعدادات هيشتغل مباشرة (audioplayers).

ملاحظة: الإشعار المجدول وقت كل صلاة (flutter_local_notifications) بيستخدم صوت
النظام الافتراضي حالياً، مش صوت الأذان الكامل، لأن تشغيل صوت مخصص طويل مع
الإشعار محتاج خطوة إضافية (وضع الملفات في android/app/src/main/res/raw
وربطها بـ RawResourceAndroidNotificationSound). قولّي لو عايزني أضيفها.
