# تطبيق "صلي" - دليل تشغيل وهيكل مشروع Flutter

أهلاً بك في تطبيق **صلي** (Salli App)، الرفيق الروحي المتكامل المطور بالكامل بلغة **Dart** وإطار العمل **Flutter** للمساعدة على الالتزام بالصلاة، تقليل المشتتات والخشوع اليومي.

---

## 🎨 الهوية البصرية والتصميم
تم استخدام أحدث لغات التصميم **Material Design 3** بالتكامل مع تأثيرات الزجاج والمظهر الداكن الروحاني (Deep Emerald Slate):
- **الألوان الأساسية**: الأخضر الزمردي المضيء (Emerald Green)، الذهب والكهرمان (Amber & Gold)، وخلفيات أثيرية عميقة (Slate Abyss) مريحة للعين وممتازة للتأمل.
- **الخطوط**: خط **Cairo** الأنيق للعناوين ومحتوى التطبيق، وخط **Amiri** للنص القرآني لتجربة بصرية وتعبدية أصيلة بنسبة ١٠٠٪.

---

## 🛠️ هيكلية ومجلدات المشروع (Clean Architecture)
يتبع المشروع معايير هندسة البرمجيات النظيفة ومبادئ SOLID لتسهيل الصيانة والتوسع:

```text
lib/
├── core/
│   ├── routes/              # إدارة مسارات GoRouter لتبديل التبويبات بسلاسة
│   ├── theme/               # مظهر الألوان الفاتح والداكن (Material 3)
│   └── utils/               # حساب مواقيت الصلاة وصيغ التاريخ الهجري بدقة
├── features/
│   ├── prayer/              # مجلد الصلاة (الرئيسية، الورد، حساب المواقيت)
│   │   ├── domain/models/   # نماذج بيانات الصلوات (PrayerTimeModel)
│   │   └── presentation/    # شاشات الواجهة (HomeScreen) والعدادات التنازلية
│   ├── quran/               # القارئ الشريف للفهرس والآيات وعلامات المرجعية
│   ├── azkar/               # الورد والأذكار مع عدادات تسبيح تفاعلية وحركية
│   ├── stats/               # الرسوم البيانية ومؤشر الالتزام الأسبوعي والسنوي
│   └── settings/            # إعدادات لغة الواجهة، صوت المؤذن والنسخ السحابي
└── main.dart                # نقطة الانطلاق والتكامل مع Firebase
```

---

## ⚡ خدمات السحابة والتحكم (Firebase Integration)
تم بناء هيكل السحابة بالكامل باستخدام خدمات Firebase المتكاملة:
1. **Firebase Authentication**: لتسجيل الدخول السلس (Google, Apple, Email, Guest).
2. **Cloud Firestore**: قاعدة بيانات موزعة لتخزين تقدمك، وأوسمتك، ونقاطك السحابية بشكل آمن وفوري.
3. **Firebase Remote Config**: للتحكم بمقاييس الحساب وصوت المؤذن الافتراضي ديناميكياً بدون الحاجة لتحديث التطبيق.
4. **Firebase App Check**: لتأمين اتصالات التطبيق بقاعدة البيانات ومنع الهجمات الخبيثة.

## 🚀 طريقة التشغيل والتركيب

### المتطلبات المسبقة:
- تثبيت Flutter SDK الإصدار `3.2.0` أو أعلى.
- بيئة تطوير متكاملة مثل VS Code أو Android Studio.

### خطوات التشغيل:
1. قم بفك الضغط والدخول إلى مجلد المشروع:
   ```bash
   cd flutter_project
   ```
2. جلب وتحديث حزم الاعتماديات (Dependencies):
   ```bash
   flutter pub get
   ```
3. إضافة إعدادات Firebase الخاصة بك في المجلدات المناسبة:
   - للـ **Android**: ضع ملف `google-services.json` داخل مجلد `android/app/`.
   - للـ **iOS**: ضع ملف `GoogleService-Info.plist` داخل مجeld `ios/Runner/`.
4. تشغيل التطبيق على المحاكي أو جهازك الشخصي:
   ```bash
   flutter run
   ```

## 🔐 نظام القواعد الأمنية المطبق (Security Rules)
تم تجهيز ملف `firestore.rules` لحماية خصوصية المستخدم ومنع تسريب البيانات. يعتمد على مصفوفة صلاحيات صارمة:
- لا يمكن للمستخدم القراءة أو الكتابة إلا على بياناته الشخصية الفريدة فقط (`request.auth.uid == userId`).
- تفعيل التحقق الهيكلي التلقائي من الحقول المطلوبة لضمان سلامة قاعدة البيانات ضد البيانات المشوهة.
