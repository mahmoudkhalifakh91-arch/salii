# تطبيق صلي (Salli) - مشروع Flutter أصلي 📱🕌

تطبيق إسلامي شامل وحديث مبني باستخدام **Flutter (Dart)** يعمل بنسبة **100% بدون إنترنت (Offline-First)** على هواتف **Android** و **iOS**.

---

## 🌟 المميزات المضمنة في كود Flutter:

1. **مواقيت الصلاة الفلكية الدقيقة أوفلاين**:
   - حساب مواقيت الصلاة فلكياً باستخدام مكتبة `adhan` الموثوقة.
   - دعم الهيئات الإسلامية الكبرى (الهيئة المصرية العامة للمساحة، أم القرى، رابطة العالم الإسلامي، ISNA).
   - مؤقت العد التنازلي المباشر للصلاة القادمة.
   - حساب وتاريخ التقويم الهجري والميلادي.

2. **القرآن الكريم كاملاً (114 سورة أوفلاين)**:
   - نص القرآن الكريم كاملاً بترميز عثماني أصلي عبر مكتبة `quran`.
   - تقسيم السور مع أسماء السور، نوعها (مكية / مدنية)، وعدد آياتها.
   - قراءة السور مع آيات مرقمة ورموز نهايات الآيات وتكبير الخط.
   - حفظ العلامات المرجعية للرجوع لآخر موضع قرأته.

3. **حصن المسلم والأذكار مع المسبحة الإلكترونية**:
   - أذكار الصباح، المساء، النوم، ما بعد الصلاة، والاستيقاظ.
   - سبحة إلكترونية تفاعلية مع اهتزاز لمسي (Haptic Vibration) عند الضغط وتصفير العداد.
   - إحصائيات التسبيح ومعدل الإنجاز.

4. **بوصلة القبلة التفاعلية**:
   - توجيه مباشر نحو الكعبة المشرفة بناءً على موقع الجهاز ومستشعر البوصلة (`flutter_compass`).

5. **الإشعارات والأذان في الخلفية**:
   - جدولة إشعارات الأذان في وقت كل صلاة عبر `flutter_local_notifications`.

## 🚀 كيفية تشغيل المشروع على جهازك:

### المتطلبات:
- تثبيت [Flutter SDK](https://flutter.dev/docs/get-started/install) (الإصدار 3.0 فما فوق).
- بيئة تطوير: **Android Studio** أو **VS Code** (مع إضافة Flutter & Dart).

### خطوات التشغيل:
1. افتح مجلد `flutter_project` في موجه الأوامر (Terminal):
   ```bash
   cd flutter_project
   ```
2. تثبيت الحزم والمكتبات:
   ```bash
   flutter pub get
   ```
3. توصيل هاتفك أو تشغيل المحاكي (Emulator)، ثم تشغيل التطبيق:
   ```bash
   flutter run
   ```
4. لبناء ملف APK للأندرويد:
   ```bash
   flutter build apk --release
   ```
   أو لـ iOS:
   ```bash
   flutter build ipa
   ```
